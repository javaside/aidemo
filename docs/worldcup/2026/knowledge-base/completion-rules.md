# 世界杯知识库补全规则

本规则用于减少“待补充”，同时避免把未经确认的信息写入知识库。所有字段都必须能追溯到来源；不能确认时保留缺口，并说明缺口类型。

## 1. 字段优先级

| 优先级 | 字段类型 | 例子 | 补全策略 |
| --- | --- | --- | --- |
| P0 | 硬事实 | 球衣号码、出生日期、年龄、身高、惯用脚、俱乐部、联赛、国家队出场/进球、教练年龄 | 只写来源能直接确认的事实；不同来源冲突时优先官方 |
| P1 | 赛前动态 | 伤病、停赛、预计首发、赛前可出战状态、主教练发布会信息 | 必须标注时间点；赛前 24 小时内来源优先 |
| P2 | 分析数据 | 近 10 场正式比赛、控球率、射门、定位球、反击、跑动、防空 | 能取得结构化数据时填写；无法公开取得时写“公开源未取得” |
| P3 | 分析判断 | 技术特点、大赛经验评级、关键球员依赖度、心理韧性 | 必须基于 P0/P1/P2 或可靠文字来源归纳，不能只凭印象 |

## 2. 来源优先级

| 等级 | 来源 | 适用字段 |
| --- | --- | --- |
| S1 | FIFA 官方赛事页、比赛页、球队页、Squad Lists PDF、各国足协官网 | 官方名单、球衣号码、身高、俱乐部、国家队出场/进球、伤病/停赛、教练任命、赛程 |
| S2 | 俱乐部官网、联赛官网、球员注册页 | 俱乐部、联赛、身高、惯用脚、伤病公告 |
| S3 | FourFourTwo、Guardian、BBC、Sky Sports、U.S. Soccer、RotoWire 等可靠媒体/机构 | 预计首发、战术风格、近期状态、比赛预览 |
| S4 | Wikidata、Wikipedia、Transfermarkt、FBref、Sofascore 等公开数据库 | 出生日期、身高、国家队履历、基础统计；需注意更新时间 |
| S5 | 非权威聚合站、社媒、论坛 | 不直接写入事实字段，只能作为待核验线索 |

## 3. 缺失字段写法

| 情况 | 写法 | 说明 |
| --- | --- | --- |
| 尚未查找 | `待补充` | 当前批次未处理该字段 |
| 查找过但公开源没有稳定数据 | `公开源未取得` | 适用于定位球、跑动、反击等统计 |
| 赛前仍未公布 | `待赛前确认` | 适用于首发、伤停、停赛名单 |
| 多源冲突 | `来源冲突，待官方确认` | 不选择更顺眼的值 |
| 需付费数据源 | `需付费数据源确认` | 适用于 Opta/StatsBomb 类细项 |

## 4. 年龄口径

- 球员年龄统一以 2026-06-11，世界杯开幕日为基准。
- 教练年龄可按知识库快照日计算，并在字段中写明“以 2026-06-12 计”。
- 若只确认出生日期但未计算年龄，格式为 `YYYY-MM-DD / 待计算`。

## 5. 球员字段补全口径

| 字段 | 首选来源 | 备注 |
| --- | --- | --- |
| 号码 | FIFA 官方名单、足协名单 | 赛前注册号码可能变化，必须以官方为准 |
| 姓名/全名 | FIFA 官方名单、足协名单 | 常用名和全名不同则分别保留 |
| 出生日期/年龄 | FIFA、足协、俱乐部、Wikidata | 年龄按统一口径计算 |
| 身高/惯用脚 | FIFA、俱乐部、联赛注册页、Transfermarkt | 来源缺失时不要推断 |
| 俱乐部/联赛 | FIFA、足协、俱乐部 | 转会窗口期需标注快照日 |
| 国家队出场/进球 | FIFA、足协、National Football Teams、Soccerway | 必须标注统计截止日 |
| 世界杯经历 | FIFA 历史页、过往世界杯名单 | 只写可确认届数/角色 |
| 当前状态 | 赛前发布会、官方伤病、可靠比赛预览 | 必须标注“截至”时间 |
| 技术特点 | 可靠 scouting 报告、比赛数据、长期位置角色 | 保持 2-3 点，避免夸张 |
| 大赛经验 | 本规则评级 | 高/中/低必须可解释 |

## 6. 大赛经验评级

| 评级 | 规则 |
| --- | --- |
| 高 | 参加过世界杯或多届洲际大赛，或在五大联赛/欧战长期主力并承担国家队核心角色 |
| 中 | 国家队轮换/主力候选，有洲际赛事或高水平联赛经验，但世界杯经验有限 |
| 低 | 国家队新人、U23/青年队上升球员，或大赛出场证据不足 |

## 7. 更新与校验

1. 每次补全前先运行缺口统计脚本，保存当前缺口数。
2. 每个新增来源都登记到 `sources.md`。
3. 每个球队文件更新 `last_updated` 和 `data_status`。
4. 每次补完一批运行：

```bash
python3 docs/worldcup/2026/knowledge-base/scripts/audit_gaps.py --teams canada bosnia-and-herzegovina united-states paraguay
git diff --check -- docs/worldcup/2026/knowledge-base
```

5. 只提交本批相关文件，不提交浏览器临时文件或未跟踪工具目录。
