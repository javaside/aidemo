# 世界杯赛前对战分析维度

本文档定义后续分析任意两支国家队时固定使用的赛前分析维度。目标是支持赛前判断，而不是赛后复盘；所有评分必须基于本地知识库、官方/可靠赛前来源、体彩对阵页和临场首发伤停信息，不得编造。

## 1. 固定输出格式

每场比赛固定输出两张柱状图和一段读图结论：

1. `关键维度柱状图`：只比较本场对战的两支球队。
2. `赛果倾向指数柱状图`：只展示本场胜/平/负三个方向。
3. `读图结论`：只写主线、主要风险点、需要临场确认的关键变量。

不要把多场比赛混在同一张关键维度图里。若一天有多场比赛，每场分别生成两张图。

## 2. 关键维度柱状图

关键维度柱状图固定使用以下 10 个维度。分值采用 1-10 的定性强弱指数，10 表示该维度优势最强。评分不是概率，只用于横向比较两队赛前条件。

| 顺序 | 维度 | 主要看什么 | 评分依据 |
| --- | --- | --- | --- |
| 1 | 主客场环境 | 主场/客场、东道主身份、旅途、气候、观众压力、比赛地适应性 | 赛程、场地、主客队身份、历史主场表现 |
| 2 | 阵容质量 | FIFA 排名、球员俱乐部层级、核心球员能力、各位置深度 | 国家队基础信息、球员名单、俱乐部和联赛层级 |
| 3 | 阵容可用性 | 伤病、停赛、核心是否首发、体能和刚复出风险 | 官方伤停、赛前发布会、体彩伤停页、可靠媒体 |
| 4 | 近期状态 | 近 10 场胜平负、进失球、零封、对手强弱、近期走势 | 体彩对阵页、FIFA/足协赛程、正式比赛优先 |
| 5 | 进攻创造 | 控球推进、边路突破、关键传球、前场连接、创造机会能力 | 战术风格、核心中前场、近期进攻表现 |
| 6 | 终结能力 | 中锋状态、核心射手稳定性、禁区把握、替补攻击手 | 球员进球数据、近期进球、锋线配置 |
| 7 | 中场控制 | 控球、压迫、抗压出球、二点球、节奏掌控 | 中场组合、教练战术、近期比赛节奏 |
| 8 | 防守组织 | 门将、中卫、边后卫保护、站位纪律、近况失球 | 失球数据、后防核心、门将稳定性 |
| 9 | 转换攻防 | 反击速度、防反能力、丢球后回防、边路身后空间 | 战术风格、边路速度、后场回追能力 |
| 10 | 定位球攻防 | 角球、任意球、高点、二点保护、防定位球能力 | 高点球员、定位球进球/失球、身高与对抗 |

## 3. 赛果倾向指数柱状图

赛果倾向指数图用于表达赛前主线，不等于真实概率，也不等于投注建议。

| 方向 | 含义 |
| --- | --- |
| 主胜 | 主队赢球倾向 |
| 平局 | 双方僵持、热门方受阻、弱势方拿分倾向 |
| 客胜 | 客队赢球或爆冷倾向 |

指数总和建议为 100，便于读图。例如：主胜 52、平局 28、客胜 20。

赛果倾向指数需要综合关键维度，并额外考虑以下赛前变量：

| 变量 | 用法 |
| --- | --- |
| 主客场环境 | 必须纳入，尤其是东道主、长途旅行、气候和场地 |
| 临场首发 | 若核心缺阵，需要下调相关方向 |
| 伤病/停赛 | 影响阵容可用性，也会影响赛果指数 |
| 让球/SP 变化 | 仅在数据明确时作为热度和风险提示，不硬编 |
| 历史交锋 | 有样本且对当前阵容仍有参考价值时使用；无样本不强行加入 |
| 小组赛形势 | 首轮、必须拿分、保平可接受等会改变比赛策略 |

## 4. 评分原则

| 分值 | 含义 |
| --- | --- |
| 9-10 | 明显优势，本场极可能成为主导因素 |
| 7-8 | 优势较清楚，对比赛走势有重要影响 |
| 5-6 | 接近或略有优势，需要结合其他维度判断 |
| 3-4 | 明显短板或受限 |
| 1-2 | 严重劣势，通常只在客场环境、重大伤停等情况使用 |

评分必须写明来源和依据。若某维度缺少可靠信息，使用保守分值，并在读图结论中标注“待赛前确认”。

## 5. 图表标题规范

每场比赛使用以下固定标题：

```text
关键维度柱状图：{主队} vs {客队}
赛果倾向指数柱状图：{主队} vs {客队}
```

图表副标题只写最关键的读图信息，不写长段解释。例如：

```text
加拿大强在主场、转换速度和防守稳定；波黑强在定位球攻防。
主线是加拿大胜；主要风险是平局。
```

## 6. 读图结论模板

```text
读图结论：
- 主线：{主胜/平局/客胜}。
- 主要风险：{最可能改变赛果的 1-2 个因素}。
- 临场确认：{核心首发/伤停/让球SP变化等}。
```

## 7. 禁止事项

1. 不把多场比赛合并到同一张关键维度图。
2. 不把指数写成真实概率。
3. 不在缺少来源时编造伤病、首发、赔率或统计数据。
4. 不使用每天变化的维度名称；如需新增维度，先更新本文档。
5. 不用长篇文字覆盖图表结论，赛前输出以图表和简短读图结论为主。
